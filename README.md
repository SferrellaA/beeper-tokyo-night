# Themes

Custom themes, grouped by the app they target. Each folder is one app. A theme inside that folder is one look, with its own install notes.

## Beeper Desktop

CSS loaded as `custom.css`. Install steps are in [beeper/README.md](beeper/README.md).

- [Tokyo Night](beeper/tokyo-night.css) — dark mode is [Tokyo Night](https://github.com/enkia/tokyo-night-vscode-theme); light mode is Tokyo Night Day.
- [Frutiger Aero](beeper/frutiger-aero.css) — day is Vista-style sky glass; night is the same look as aurora over deep water.

## Windows Terminal

- [Frutiger Aero](windows-terminal/frutiger-aero/README.md) — pale sky by day, deep water at night. Color schemes, a window theme, and a sky picture. WSL tabs pick it up because Windows Terminal draws them.
